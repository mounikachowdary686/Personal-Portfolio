## Brand & Style
The design system establishes a hyper-modern, technically elite aesthetic tailored for high-velocity AI startups, visionary researchers, and competitive hackathon champions. It merges dark-mode computational density with an ethereal, luminous interface. 

The aesthetic is grounded in a hybrid of **Glassmorphism** and **High-Contrast Dark Sci-Fi**. It reflects computational mastery, machine intelligence, and uncompromising technical precision. Key attributes:
- **Atmospheric Luminosity:** Deep midnight backdrops layered with multi-spectrum radial energy nodes (ambient blur fields in violet and cyan).
- **Sub-pixel Precision:** Micro-borders, luminous surface gradients, and crisp monospaced telemetry juxtaposed with modern geometric sans-serifs.
- **Aggressive Hierarchy:** Razor-sharp typography and high-voltage accents evoke the speed and intensity of breakthrough artificial intelligence delivery.

## Colors
The palette is built on deep void tones layered with energized luminescent signals.

### Surface Tones
- **Void Base (`#060814`):** Canvas backdrop for deep visual grounding.
- **Sub-surface / Abyss (`#0b0f1f`):** Structural layers, nested containers, and sheet backdrops.
- **Glass Fill (`rgba(11, 15, 31, 0.65)`):** Dynamic semi-translucent surface with background blur.
- **Surface Highlight (`rgba(255, 255, 255, 0.04)`):** Internal light catchers.

### Accents & Kinetic Highlights
- **Primary / Hyper Cyan (`#00f5ff`):** Interactive focal points, active states, key metric highlights, and terminal signals.
- **Secondary / Deep Violet (`#8b5cf6`):** Ambient atmospheric fields, brand motifs, primary-to-secondary gradients.
- **Tertiary / Electric Sky (`#38bdf8`):** Secondary data visualizations, active links, code structures.
- **Accent Purple Glow (`#a855f7`):** Edge-glow highlights, radial backdrop orbs.

### Text & Contrast Hierarchy
- **Text High-Contrast (`#f8fafc`):** Primary headings, key metrics, critical copy.
- **Text Medium-Contrast (`#94a3b8`):** Body copy, descriptions, secondary specifications.
- **Text Low-Contrast (`#475569`):** Metadata, grid markers, placeholder text.

## Typography
Plus Jakarta Sans provides high-clarity geometry with contemporary character, optimizing legibility across wide dynamic ranges. JetBrains Mono balances the visual language by grounding UI elements in raw computational authority.

- **Display & Headings:** Use tight negative letter-spacing (`-0.02em` to `-0.04em`) to establish visual tension and high impact. Use background gradient clipping (Cyan to Violet) on primary hero text.
- **Body:** Neutral grey rendering with balanced line heights to maintain high contrast readability against dark translucent planes.
- **Labels & Badges:** Render tech badges, metric labels, commit hashes, and system stats exclusively in JetBrains Mono with uppercase styling and expanded tracking.

## Layout & Spacing
The layout follows a fluid-responsive 12-column grid system anchored by a maximum content container of `1280px`.

### Responsive Breakpoints
- **Mobile (< 768px):** 4-column structure with `1.25rem` outer margins and `1rem` gutters. Stacks cards and stats horizontally.
- **Tablet (768px - 1024px):** 8-column structure with `2rem` outer margins and `1.5rem` gutters.
- **Desktop (> 1024px):** 12-column structure with `3rem` outer margins and `1.5rem` gutters.

### Rhythm
Component internals use strict binary powers (`0.5rem`, `1rem`, `1.5rem`, `2.5rem`). Structural sections are given room to breathe with vertical padding between `5rem` and `8rem`, allowing ambient blur orbs to bleed across grid sections without visual clutter.

## Elevation & Depth
Depth is created through chromatic backdrops, optical glass layers, and micro-borders rather than standard black drop shadows.

### Elevation Levels
1. **Level 0 (Canvas):** Pure `#060814` canvas interspersed with fixed-position radial blur lights:
   - Primary Orb: `radial-gradient(circle, rgba(139, 92, 246, 0.15) 0%, transparent 70%)` with a `120px` blur.
   - Secondary Orb: `radial-gradient(circle, rgba(0, 245, 255, 0.12) 0%, transparent 65%)` with an `80px` blur.
2. **Level 1 (Sub-Panels / Recessed):** Solid `#0b0f1f` with a subtle outline: `1px solid rgba(255, 255, 255, 0.05)`.
3. **Level 2 (Glassmorphic Cards):** 
   - Background: `rgba(11, 15, 31, 0.70)`.
   - Backdrop filter: `blur(16px) saturate(180%)`.
   - Border: `1px solid rgba(139, 92, 246, 0.25)` top-left transitioning to `rgba(0, 245, 255, 0.2)` bottom-right.
   - Shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.6)`.
4. **Level 3 (Interactive / Hover):**
   - Background: `rgba(15, 23, 42, 0.8)`.
   - Border: `1px solid rgba(0, 245, 255, 0.6)`.
   - Box-Shadow: `0 0 25px rgba(0, 245, 255, 0.25), 0 16px 40px -8px rgba(0, 0, 0, 0.8)`.
5. **Level 4 (Modals & Overlays):**
   - Background: `rgba(6, 8, 20, 0.92)`.
   - Backdrop filter: `blur(24px)`.
   - Border: `1px solid rgba(168, 85, 247, 0.4)`.
   - Box-shadow: `0 24px 64px -12px rgba(0, 0, 0, 0.9), 0 0 40px rgba(139, 92, 246, 0.2)`.

## Shapes
Roundedness sits at Level 2, balancing technical precision with contemporary product aesthetics:
- Base components (inputs, regular badges, buttons) use `0.5rem` (`8px`) radii.
- Content containers, structural panels, and project cards use `rounded-lg` at `1rem` (`16px`).
- Feature showcases and hero glass banners scale to `rounded-xl` at `1.5rem` (`24px`).
- Interactive indicator pills and status indicators use fully rounded edge caps (`9999px`).

- **Secondary Glass:** Background `rgba(255, 255, 255, 0.03)`, text `#f8fafc`, micro-border `1px solid rgba(139, 92, 246, 0.4)`. Hover: background `rgba(139, 92, 246, 0.15)`, border `1px solid #a855f7`.
- **Ghost Monospace:** JetBrains Mono font, transparent background, text `#38bdf8`. Hover: text `#00f5ff`, background `rgba(0, 245, 255, 0.05)`.

### Cards & Project Showcases
- Glassmorphic panels with `backdrop-filter: blur(16px)`. Dual-tone gradient borders (violet-to-cyan) rendered via background-clip or layered pseudo-elements.
- Inner card headers feature live hackathon win tags or production metrics.
- Hover states initiate smooth border illumination shifts and faint inner cyan glows.

### Badges & Tech Chips
